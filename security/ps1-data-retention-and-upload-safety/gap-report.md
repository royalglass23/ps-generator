# Gap report — PS1 data retention and upload safety

| Priority | Gap | Earliest corrective action |
|---|---|---|
| 1 | High: unscanned structurally valid files are directly attached to staff mail | Add a verified pre-delivery malware control or replace attachments with controlled retrieval before seeking a Secure SDLC PASS. |
| 2 | Strict E2E 0/10 | Exercise the exact ZIP on isolated staging with synthetic mail, deterministic roles/time, real cron, and a managed Defender endpoint; record zero-retry evidence. |
| 3 | Silent scheduled-job failures | Add non-PII alerting for cleanup, escalation, deletion, mail, and missed cron. |
| 4 | Mailbox/device copies outlive WordPress | Define Microsoft 365/mailbox/download retention and incident procedures. |
| 5 | Broader public privacy/deployment controls | Verify notice, access/correction process, TLS/headers/CORS, backups, processor terms, and breach response. |

The user explicitly accepted priorities 1 and 4 for the current operating model. That is business risk acceptance, not security PASS evidence.
