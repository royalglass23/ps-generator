# PS1 Prototype Scope

This list keeps the prototype aligned with Roxy's original P1 logic while retaining later ideas without silently adding them to the customer journey.

## Current P1

- Let the applicant visually select the balustrade or pool-barrier system they are considering.
- Provide "Other" and "Not Sure" choices.
- When the applicant is unsure, invite a drawing, photograph, sketch or inspiration image for Royal Glass review.
- Do not ask the applicant to decide whether the project is standard or specific design.
- Use clearly illustrative placeholder images in the prototype only.
- Replace placeholders with approved Royal Glass system or project images before production.
- For P1, retain Roxy's simple system categories rather than exposing the old PS Generator's full technical catalogue.
- Keep the system catalogue replaceable so approved products, names, images and technical options can be introduced later without redesigning the journey.

## Good to have later

- Let Royal Glass staff assign an internal design-pathway classification after technical review, if that classification proves useful for work routing, reporting or engineering handoff.
- Keep any internal classification out of the customer form unless Royal Glass confirms that the applicant can answer it reliably.
