# PS1 system application classification

**Research date:** 6 October 2026
**Question:** Which system options currently shown by the PS1 application belong to glass balustrades, pool fences/barriers, both, or remain unclear?

## Executive conclusion

The application can pre-filter most of the current catalogue without asking the applicant to identify every system. Twelve of the fourteen named options have official evidence for use in **both** balustrade and pool-barrier configurations. Ten of those are glass-system entries; **Unex Ascot** and **Viking Aluminium** are non-glass aluminium configurations. Two labels need Royal Glass confirmation before they should be automatically routed: **Hidden Face** is not a unique product identifier, and **Juralco Canopy** is an awning/canopy rather than a balustrade or pool-barrier system. **Not sure** is a workflow fallback, not a product system.

This is a catalogue classification, not project approval. A product that supports both applications still needs the correct glass, rail, gate hardware, fixing, substrate, height, wind/loading and manufacturer-specific design. New Zealand Building Code clause F4 addresses barriers where people could fall one metre or more, while F9/AS1 separately addresses barriers restricting unsupervised access by children to residential pools. ([MBIE F4 barrier guidance](https://www.building.govt.nz/building-code-compliance/f-safety-of-users/f4-safety-from-falling/barriers-and-handrails/), [MBIE F9/AS1](https://www.building.govt.nz/assets/Uploads/building-code-compliance/f-safety-of-users/f9-restricting-access-residential-pools/asvm/f9-restricting-access-to-residential-pools.pdf))

## Recommended selector behaviour

For a first catalogue pass, the application can use this routing:

- **Glass balustrade:** show Double Disc, JH Clamp, Lugano, Mini Post, Mini Post SP14, Side Mount Channel, Top Mount Channel, Unex Metropolis, Viking Glass and Vista.
- **Pool fence / pool barrier:** show those same ten glass options. If Royal Glass intends this choice to include aluminium pool barriers as well as glass, also show Unex Ascot and Viking Aluminium; otherwise exclude them.
- **Always show:** Not sure.
- **Hold back pending confirmation:** Hidden Face and Juralco Canopy.

Because all confirmed glass options are dual-use, filtering alone will not materially shorten either list yet. The more useful catalogue improvement is to replace generic names with exact product identifiers and then attach approved images plus application-specific configurations.

## Confirmation required from Royal Glass

Royal Glass does **not** need to manually classify every system from scratch. The official evidence is sufficient to pre-classify the twelve dual-use options above. Confirmation is still required for these catalogue ownership questions:

1. What exact manufacturer/product does **Hidden Face** mean?
2. Is **Juralco Canopy** intentionally part of the PS1 application, or is it legacy data that should move to a canopy-specific journey?
3. Do **Double Disc**, **Mini Post**, **Side Mount Channel** and **Top Mount Channel** refer to Royal Glass house systems, Opus, Metro, Juralco, or another supplier? The application category is clear, but the PS1/design documentation cannot be linked safely until the identity is explicit.
4. Should **Unex Ascot** and **Viking Aluminium** appear in a journey labelled “glass balustrade or pool fence,” given that these are aluminium/non-glass choices?

## Regulatory guardrail

“Both” must not be implemented as “the same specification works for both.” MBIE distinguishes ordinary fall-protection barriers under F4 from residential pool-access barriers under F9/AS1, and manufacturers publish different heights, rails, gates, glass and design limits by use. The UI may filter by supported application, but Royal Glass or the system's technical documentation must still validate the selected project configuration. ([MBIE F4/AS1](https://www.building.govt.nz/building-code-compliance/f-safety-of-users/f4-safety-from-falling/acceptable-solutions-and-verification-methods), [MBIE F9/AS1](https://www.building.govt.nz/assets/Uploads/building-code-compliance/f-safety-of-users/f9-restricting-access-residential-pools/asvm/f9-restricting-access-to-residential-pools.pdf), [MBIE F2/NZS 4223.3 update](https://www.building.govt.nz/building-code-compliance/f-safety-of-users/f2-hazardous-building-materials/acceptable-solutions-and-verification-methods/1st-edition-amendment-3))
